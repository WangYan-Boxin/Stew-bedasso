# Happy Sheep Jump 🐑

A fun and interactive 2D side-scroller jumping game built with Python and Pygame! Help Happy Sheep dodge Wolffy and various obstacles to challenge for the highest score.

---

## 🎮 How to Play

* **Basic Jump**: Press the `Spacebar` or the `Up Arrow (↑)` key to make Happy Sheep jump over incoming obstacles on the ground.
* **Destroy Obstacles**: When encountering an obstacle with a **red border**, you can jump onto it and press the `Spacebar` again to destroy it!
* **Fast Descend**: Press the `Down Arrow (↓)` key while in mid-air to fast-descend back to the ground quickly.
* **Scoring**: Your score continuously increases the longer you survive and successfully evade or destroy obstacles.
* **Game Over**: The game ends if you collide with an obstacle normally (without destroying it), triggering a destruction sound effect.
